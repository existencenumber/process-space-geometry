# Process Space Geometry - Verification Repository

This repository contains the complete reference implementation for reproducing all numerical results reported in:

**W. Xu, "Process Space Geometry: A First-Principles Derivation of Fundamental Physical Constants" (2026)**

- Part I: Theoretical Framework and the Fine-Structure Constant
- Part II: The Weinberg Angle, Strong Coupling, and Mass Ratios

## Quick Start

### Prerequisites

- Python 3.8 or later
- pip package manager

```bash
git clone https://github.com/wanpeng-xu/process-space-geometry.git
